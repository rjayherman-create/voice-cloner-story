## 🎯 How to Use Cartoon Voices

### Step 1: Switch to Cartoon Tab
1. Open http://localhost:5001
2. Create a project
3. Click **"🎭 Cartoon"** tab in the voice selector

### Step 2: Choose a Voice
- **Villain** - For antagonists or dramatic moments
- **Hero** - For main characters on adventures
- **Sidekick** - For comic relief and support
- **Young Character** - For child voices
- Search bar to find specific voices

### Step 3: Select Emotion
Different emotions create variety:
- **Happy** → Cheerful villain laugh
- **Serious** → Dramatic hero monologue
- **Excited** → Over-the-top adventure call
- **Sad** → Emotional character moment
- **Angry** → Villain confrontation

### Step 4: Generate
1. Write your script
2. Select voice + emotion
3. Click **"🎬 Generate Voiceover"**
4. Download your cartoon audio! 🎉

## 💡 Pro Tips for Cartoon Voiceovers

### Tip 1: Mix Voices for Dialogue
Use different cartoon voices for different characters:
- **Voice 1** (Hero) → Lines 1, 3, 5
- **Voice 2** (Villain) → Lines 2, 4, 6

### Tip 2: Use Emotions Creatively
- Happy Villain = Creepy cheerfulness
- Sad Hero = Defeated moment
- Excited Sidekick = Over-the-top energy
- Calm Villain = Menacing threat

### Tip 3: Script for Voice
Some voices work better for certain scripts:
- **Villain voice** → Threatening dialogue
- **Hero voice** → Inspiring speeches
- **Sidekick voice** → Comic quips
- **Narrator voice** → Story explanations

### Tip 4: Keep Consistency
For main characters, use same voice throughout:
- **Hero** always uses same voice
- **Villain** consistent across scenes
- Helps audience recognize characters

### Tip 5: Batch Generation
Generate multiple variations:
1. Same character, different emotions
2. Compare all versions
3. Pick the best delivery
4. Keep in project history

## ⚙️ Technical Details

### Voice Categorization
All voices now have:
- **id** - Unique voice identifier
- **name** - Display name
- **category** - "professional" or "cartoon"
- **cartoonName** - Character name (if cartoon)
- **cartoonStyle** - Voice description/style
- **description** - Full description
- **previewUrl** - Sample audio URL

### API Endpoints

**Get Cartoon Voices Only:**
```bash
GET /api/voiceover/voices?category=cartoon
```

**Get Professional Voices:**
```bash
GET /api/voiceover/voices?category=professional
```

**Get All Voices:**
```bash
GET /api/voiceover/voices
```

**Get Specific Category:**
```bash
GET /api/voiceover/voices/category/{category}
```

## 🆘 Troubleshooting

**Q: Cartoon tab is empty?**
A: Make sure:
1. ElevenLabs API key is configured
2. Server is restarted
3. Check browser console (F12) for errors

**Q: Can't hear the cartoon voice?**
A: Check:
1. Browser volume is on
2. Audio player is working
3. Try preview first

**Q: Want different cartoon voices?**
A: You can customize voice mapping in:
```
backend/services/elevenlab-service.js
getCartoonVoiceMapping()
```
