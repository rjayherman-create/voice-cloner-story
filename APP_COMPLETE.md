## 🎬 HOW TO USE

### Creating Voiceovers

1. **Create a Project**
   - Click "+ New Project"
   - Name: "My Cartoon" or "Commercial Ad"
   - Description (optional)

2. **Write Your Script**
   - Enter text in script editor
   - See character count and duration estimate

3. **Choose Voice Type**
   - **Professional Tab** - For narration, commercials
   - **🎭 Cartoon Tab** - For characters, animation

4. **Pick Specific Voice**
   - See all available voices
   - Search to filter
   - Read description

5. **Select Emotion**
   - Choose how you want it delivered
   - Same script sounds different per emotion

6. **Generate**
   - Click "🎬 Generate Voiceover"
   - Wait 2-5 seconds
   - Download MP3!

7. **Compare & Keep**
   - Try different variations
   - All saved in project history
   - Delete ones you don't want
