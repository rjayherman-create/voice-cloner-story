## ❓ Need Help?

### If Authentication Fails
Use Personal Access Token:
1. Go to https://github.com/settings/tokens
2. Create new token (classic)
3. Select: repo, workflow
4. Use token instead of password

### If Port 5001 Already Used
```bash
# Kill process
lsof -i :5001
kill -9 <PID>

# Or change in docker-compose.yml: "8080:5001"
```

### If Build Fails
```bash
docker-compose build --no-cache
docker-compose up -d
```
